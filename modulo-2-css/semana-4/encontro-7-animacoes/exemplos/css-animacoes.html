Guia CSS: Transicoes e Animacoes

Neste guia, voce vai ver como pequenos movimentos deixam uma interface mais viva. Os exemplos mostram efeitos sutis para hover, entrada de elementos, destaque visual e acessibilidade com movimento reduzido.

1. Card com elevacao no hover

Transicoes ajudam o usuario a perceber que um item pode ser interagido. Aqui, o card sobe alguns pixels e ganha sombra quando o mouse passa por cima.

Destaque

Prato da Casa

Um hover suave deixa o card mais claro e convidativo.

<article class="card card--hover">
    <span class="card__tag">Destaque</span>
    <h3>Prato da Casa</h3>
    <p>Um hover suave deixa o card mais claro e convidativo.</p>
</article>
.card--hover {
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card--hover:hover {
    transform: translateY(-6px);
    box-shadow: 0 14px 28px rgba(0, 0, 0, 0.28);
}

2. Link com mudanca de cor e sublinhado

Links tambem podem indicar interacao com suavidade. Neste exemplo, a cor muda e uma linha inferior aparece sem ser brusca.

Entradas Pratos Sobremesas 
<nav class="menu">
    <a class="menu__link" href="#">Entradas</a>
    <a class="menu__link" href="#">Pratos</a>
    <a class="menu__link" href="#">Sobremesas</a>
</nav>
.menu__link {
    border-bottom: 2px solid transparent;
    color: var(--text);
    transition: color 0.3s ease, border-bottom 0.3s ease;
}

.menu__link:hover {
    border-bottom: 2px solid var(--primary);
    color: var(--primary);
}

3. Botao com escala suave

Um botao pode ganhar destaque sem exagero. O efeito abaixo amplia levemente o elemento e reforca a ideia de clique. 

<button class="button button--cta" type="button">Pedir agora</button>
.button--cta {
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.button--cta:hover {
    transform: scale(1.05);
    box-shadow: 0 10px 20px rgba(0, 0, 0, 0.22);
}

4. Entrada com keyframes

As animacoes com @keyframes permitem controlar como um elemento aparece. Aqui, o bloco surge com opacidade crescente e um pequeno deslocamento vertical.

Novidade da semana: menu degustacao com ingredientes regionais. 
<div class="banner banner--entry">
    Novidade da semana: menu degustacao com ingredientes regionais.
</div>
@keyframes aparecer {
    from {
        opacity: 0;
        transform: translateY(-20px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.banner--entry {
    animation: aparecer 0.6s ease;
}

5. Destaque pulsando com moderacao

Uma animacao continua deve ser usada apenas quando faz sentido. Neste selo, o pulso chama atencao para uma promocao sem tomar conta da tela.

Promo 20% OFF 
<span class="badge badge--pulse">Promo 20% OFF</span>
@keyframes pulsar {
    0%, 100% {
        transform: scale(1);
    }

    50% {
        transform: scale(1.06);
    }
}

.badge--pulse {
    animation: pulsar 2s ease-in-out infinite;
}

6. Movimento reduzido para acessibilidade

Nem todo mundo se sente bem com animacoes. Esta media query reduz o impacto visual quando a pessoa usuaria sinaliza preferencia por menos movimento no sistema.

Boa pratica: respeitar a preferencia de movimento reduzido.

Isso melhora conforto e acessibilidade.

<div class="accessibility-note">
    <p>Boa pratica: respeitar a preferencia de movimento reduzido.</p>
    <p>Isso melhora conforto e acessibilidade.</p>
</div>
@media (prefers-reduced-motion: reduce) {
    *,
    *::before,
    *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}
