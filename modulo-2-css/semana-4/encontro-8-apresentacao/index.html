Encontro 8 - Apresentação dos Cardápios

Neste encontro vamos apresentar os projetos completos de HTML e CSS, trocar feedbacks e consolidar o que foi aprendido antes de seguir para o módulo de JavaScript.

Objetivos

  • Apresentar o cardápio finalizado para a turma
  • Receber e oferecer feedback técnico e visual
  • Revisar os principais conceitos do mês de CSS
  • Preparar o projeto para a próxima etapa com JavaScript

Resumo

Esta aula fecha o modulo de CSS com uma apresentacao dos projetos. O foco e perceber a evolucao do cardapio, discutir decisoes de layout e identificar os ultimos ajustes antes de adicionar interatividade.

Materiais deste tópico

Esta pasta nao possui arquivos de exemplo. Use o README como guia para revisar os criterios de apresentacao, coletar feedback e planejar os ajustes finais do projeto.
