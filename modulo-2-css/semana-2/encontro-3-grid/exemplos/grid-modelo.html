Guia Prático: CSS Grid

Aprenda os conceitos fundamentais do sistema de grid através de exemplos interativos. Clique nas abas para ver o código HTML e CSS de cada exemplo.

1. Colunas de Largura Igual

O repeat(3, 1fr) cria três colunas que ocupam espaço igual automaticamente, independente do conteúdo.

Coluna 1
Coluna 2
Coluna 3
<div class="grid-3-cols gap-2">
    <div class="grid-item">Coluna 1</div>
    <div class="grid-item">Coluna 2</div>
    <div class="grid-item">Coluna 3</div>
</div>
.grid-3-cols {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

.grid-item {
    background-color: rgba(54, 232, 143, 0.1);
    border: 1px solid var(--primary);
    padding: 15px;
    text-align: center;
    border-radius: 4px;
}

2. Layout com Sidebar Fixa

Combinação de coluna fixa (250px) com área flexível (1fr) cria layouts clássicos de sidebar.

Sidebar
(250px fixo)
Conteúdo Principal
(adapta ao espaço)
<div class="grid-sidebar-main gap-2">
    <div class="grid-item">Sidebar<br>(250px fixo)</div>
    <div class="grid-item">Conteúdo Principal<br>(adapta ao espaço)</div>
</div>
.grid-sidebar-main {
    display: grid;
    grid-template-columns: 250px 1fr;
    gap: 10px;
}

3. Responsividade com Auto-fit

O repeat(auto-fit, minmax(200px, 1fr)) cria colunas que se ajustam automaticamente ao espaço disponível, sem necessidade de Media Queries.

Card 1
Card 2
Card 3
Card 4
Card 5
Card 6
<div class="grid-auto-fit gap-2">
    <div class="grid-item">Card 1</div>
    <div class="grid-item">Card 2</div>
    <div class="grid-item">Card 3</div>
    <div class="grid-item">Card 4</div>
    <div class="grid-item">Card 5</div>
    <div class="grid-item">Card 6</div>
</div>
.grid-auto-fit {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 10px;
}

4. Layout com Áreas Nomeadas

As grid-template-areas permitem criar layouts complexos de forma semântica, nomeando regiões específicas do grid.

Header
Navigation
Main Content Area
Footer
<div class="grid-named-areas">
    <div class="grid-item area-header">Header</div>
    <div class="grid-item area-nav">Navigation</div>
    <div class="grid-item area-main">Main Content Area</div>
    <div class="grid-item area-footer">Footer</div>
</div>
.grid-named-areas {
    display: grid;
    grid-template-areas:
        "header header"
        "nav main"
        "footer footer";
    grid-template-columns: 150px 1fr;
    gap: 10px;
}

.area-header { grid-area: header; }
.area-nav    { grid-area: nav; }
.area-main   { grid-area: main; }
.area-footer { grid-area: footer; }
