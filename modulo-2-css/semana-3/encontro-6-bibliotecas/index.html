Encontro 6 - Bibliotecas CSS

Neste encontro vamos conhecer bibliotecas CSS, comparar diferentes abordagens e entender quando faz sentido usar recursos prontos no projeto do cardápio.

Objetivos

  • Conhecer bibliotecas e frameworks CSS populares
  • Entender quando usar Normalize.css, Bootstrap ou Tailwind
  • Comparar velocidade de desenvolvimento e controle visual
  • Testar abordagens diferentes no cardápio

Resumo

Bibliotecas CSS podem acelerar o desenvolvimento e trazer componentes prontos, mas tambem mudam a forma como o projeto e construido. A proposta desta aula e experimentar essas ferramentas com senso critico.

Materiais deste tópico

Esta pasta nao possui arquivos de exemplo no momento. Use o README da aula para orientar os testes com Normalize.css, Bootstrap e Tailwind diretamente no seu projeto.
