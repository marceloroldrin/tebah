Guia Prático: Metodologia BEM

Aprenda a estruturar seu CSS de forma escalável e semântica utilizando o padrão Block Element Modifier.

1. Menu de Navegação

Um exemplo clássico de BEM onde temos um Bloco (menu), Elementos (lista, item, link) e um Modificador (ativo).

  • Home
  • Produtos
  • Sobre
  • Contato
<nav class="menu">
    <ul class="menu__lista">
        <li class="menu__item">
            <a href="#" class="menu__link menu__link--ativo">Home</a>
        </li>
        <li class="menu__item">
            <a href="#" class="menu__link">Produtos</a>
        </li>
    </ul>
</nav>
.menu {
    width: 100%;
}

.menu__lista {
    display: flex;
    gap: 20px;
    list-style: none;
}

.menu__link {
    color: var(--text);
    text-decoration: none;
}

.menu__link--ativo {
    color: var(--primary);
    border-bottom: 2px solid var(--primary);
}

2. Card de Conteúdo (Componente Rico)

Demonstração de como lidar com múltiplos elementos dentro de um bloco e modificadores de destaque.

Hambúrguer Gourmet

Pão brioche, blend de 180g, queijo cheddar e bacon crocante.

R$ 35,00 
<div class="prato-card prato-card--destaque">
    <h3 class="prato-card__titulo">Hambúrguer Gourmet</h3>
    <p class="prato-card__descricao">Pão brioche...</p>
    <span class="prato-card__preco prato-card__preco--promocao">R$ 35,00</span>
</div>
.prato-card {
    background: var(--panel);
    padding: 20px;
}

.prato-card--destaque {
    border: 2px solid var(--primary);
}

.prato-card__titulo {
    color: var(--primary);
}

.prato-card__preco--promocao {
    color: #ff5555;
}

3. Botões com Modificadores

Utilização de modificadores para criar variantes de um mesmo componente base.

<button class="btn btn--primary">Confirmar</button>
<button class="btn btn--secondary">Cancelar</button>
.btn {
    padding: 10px 20px;
    cursor: pointer;
}

.btn--primary {
    background: var(--primary);
    color: var(--bg);
}

.btn--secondary {
    border: 1px solid var(--primary);
    color: var(--primary);
}

4. Alerta de Notificação

Um componente de feedback que usa modificadores para indicar o tipo de status (sucesso, erro).

✅ Cadastro realizado com sucesso!
❌ Ocorreu um erro ao processar seu pedido. 
<div class="alerta alerta--sucesso">
    <span class="alerta__mensagem">✅ Sucesso!</span>
    <button class="alerta__botao-fechar">&times;</button>
</div>
.alerta {
    display: flex;
    padding: 15px;
    border-radius: 6px;
}

.alerta--sucesso {
    background: rgba(54, 232, 143, 0.1);
    border-left: 5px solid var(--primary);
}

.alerta__mensagem {
    flex: 1;
}

5. Card de Depoimento

Exemplo de bloco complexo com elementos internos e modificador de alinhamento centralizado.

"A metodologia BEM mudou completamente a forma como organizo meus projetos. É muito mais fácil dar manutenção!"

Ana Silva 
<div class="depoimento depoimento--centralizado">
    <p class="depoimento__texto">"Frase do depoimento..."</p>
    <div class="depoimento__autor">
        <img src="..." class="depoimento__avatar">
        <span class="depoimento__nome">Ana Silva</span>
    </div>
</div>
.depoimento {
    background: var(--panel);
    padding: 25px;
}

.depoimento--centralizado {
    text-align: center;
}

.depoimento__avatar {
    width: 50px;
    border-radius: 50%;
    border: 2px solid var(--primary);
}
