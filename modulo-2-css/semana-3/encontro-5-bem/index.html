Encontro 5 - Padrão BEM

Neste encontro vamos entender o padrão BEM, aprender a nomear classes de forma mais organizada e usar essa ideia para refatorar o CSS do cardápio.

Objetivos

  • Entender o padrão BEM
  • Aprender a nomear classes de forma organizada
  • Refatorar o CSS do cardápio

Resumo

BEM significa Block, Element e Modifier. Essa metodologia ajuda a criar nomes de classes mais claros, facilita a manutenção do CSS e reduz conflitos entre estilos.
