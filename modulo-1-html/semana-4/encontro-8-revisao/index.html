Encontro 8 - Revisão e Consolidação do Mês 1

Neste encontro vamos revisar tudo o que foi aprendido em HTML, consolidar o projeto do cardápio digital e identificar o que precisa de reforço antes de avançar para CSS.

Objetivos

  • Revisar os principais conceitos de HTML
  • Consolidar a prática com um desafio final
  • Identificar pontos fortes e dúvidas restantes
  • Preparar a base do projeto para o módulo de CSS

Resumo

Esta aula fecha o primeiro ciclo do curso. O foco e reunir semantica, acessibilidade, formularios, organizacao e versionamento em um projeto mais completo, com revisao critica do que ja foi construido.

Materiais deste tópico

Este encontro nao possui arquivos de exemplo nesta pasta. Use o checklist do README para revisar o projeto, validar os requisitos e preparar seu HTML para receber estilos no proximo modulo.
