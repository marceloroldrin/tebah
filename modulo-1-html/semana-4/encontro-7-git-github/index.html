Encontro 7 - Git e GitHub Básico

Neste encontro vamos entender como salvar versões do projeto com Git, publicar o trabalho no GitHub e começar a registrar a evolução do cardápio com commits.

Objetivos

  • Entender o papel do controle de versão
  • Aprender os comandos básicos do Git
  • Publicar o projeto no GitHub
  • Ganhar mais segurança para colaborar em equipe

Resumo

Git ajuda a registrar cada etapa do projeto, enquanto o GitHub permite publicar e compartilhar esse historico. Nesta aula, o objetivo e sair do trabalho local e comecar a versionar o cardapio de forma organizada.
