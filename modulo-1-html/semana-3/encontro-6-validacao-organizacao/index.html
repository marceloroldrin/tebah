Encontro 6 - Validação e Organização de Código

Neste encontro vamos revisar o HTML do projeto, validar a estrutura com ferramentas oficiais e deixar os arquivos mais organizados para facilitar manutenção e trabalho em equipe.

Objetivos

  • Validar HTML com ferramentas confiáveis
  • Organizar pastas e nomes de arquivos
  • Padronizar indentação, comentários e headings
  • Preparar o projeto para evoluir com mais segurança

Resumo

Validar e organizar o codigo faz parte do desenvolvimento profissional. A ideia aqui e identificar erros silenciosos, melhorar a legibilidade do projeto e criar uma base mais clara para as proximas etapas.

Materiais deste tópico

Este encontro nao possui arquivos de exemplo nesta pasta. Use o README da aula e o seu proprio projeto de cardapio para praticar validacao, reorganizacao e refatoracao.
